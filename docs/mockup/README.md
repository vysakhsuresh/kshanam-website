# Mockup screens

These six files come from the Kshanam design canvas made in the planning chat.
They depend on that canvas's runtime (`support.js`), so they will not open as
normal web pages. Read them as reference for layout, copy, sizes and colours.

- Main.dc.html: home page (390 px wide phone layout)
- Details.dc.html: details form with live preview
- Share.dc.html: ready screen with share, download and feedback
- GuestLanding.dc.html: page for guests who arrive from an invite
- Invite.dc.html: Kasavu Gold invite frame (360 × 640, 9:16)
- EndCard.dc.html: optional 2-second end card
